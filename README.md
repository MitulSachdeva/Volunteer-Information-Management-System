# Volunteer Information Management System

## Features
- Volunteer Registration
- Admin Login
- Volunteer Dashboard
- SQLite Database
- REST APIs
- JWT Authentication
- Volunteer Management
- Reports & Statistics

## Tech Stack
- FastAPI
- SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript

## Run Backend

pip install -r requirements.txt
uvicorn app.main:app --reload
